SECTION 07 인사이트 IF · THEN · BECAUSE
5/14 정점 후 신청 -37% 정체 - 광고 종료 영향 IF 5/14 71건 → 5/17 45건(-37%)의 신청 감소가 5/15~5/16 duo_700+/now/story 메타 광고 3종 종료와 시기적으로 일치한다면
THEN 광고 라인업 축소가 트래픽·신청 직접 감소로 연결됨 — 5/17부터의 단순화된 라인업(duo_700+story + duo_10000)이 종료된 3종을 보완하지 못함을 시사
BECAUSE duo_700+/now/story 3종은 머신러닝(25~) 광고세트로 같은 타깃을 다른 크리에이티브로 노출하는 멀티 변형 구조였음. 단일 변형 의존 시 노출 빈도 누적으로 광고 피로도 가속화 가능
메타 참여율 6일 연속 하락 - 크리에이티브 피로 누적 IF 메타 전체 참여율이 6일 연속 하락 추세로 형성된다면
THEN 현 크리에이티브 풀의 한계 — 동일 광고가 5/17 기준 24~25일 노출 중인 듀오 개인정보유출 0423 캠페인 위주로 운영되며 새로운 자극 필요
BECAUSE 광고 노출 4주 차에 접어들면 동일 사용자 도달 빈도가 누적되어 참여율 자연 하락. 5/13부터 시작된 듀오_집단소송_260513 캠페인이 가장 신규이지만 5/17 기준 5일차로 아직 신선도 유지 중. 다음 신규 캠페인 투입 시점 검토 필요
네이버SA CPC 점진 개선 - 키워드 등급 전략 효과 IF 네이버SA 캠페인 CPC가 주중 -45% 개선되어 5/17 ₩1,316까지 하락한다면
THEN 고가 키워드 입찰 조정과 저가 핵심 키워드 강화의 단계적 효과 — 5/18 다시 -38% 추가 하락(₩816)을 보여 추세 지속성 확인됨
BECAUSE 주간 키워드 분석상 듀오집단소송·듀오단체소송 등 일반 의도 키워드의 평균 CPC가 ₩1,100~1,500인 반면, 듀오개인정보소송·듀오유출소송 등 구체 의도 키워드는 ₩59~77 수준. 점진적 비드 재배분이 안정화 단계 진입 중
네이버 검색어 확장 비효율 - 신규 18종 중 클릭 1건 IF 5/17 등장한 신규 검색어 18종에서 클릭이 단 1건(전환 0)이라면
THEN 키워드 확장 매칭 옵션(확장형)에서 발견된 신규 검색어들이 실제 의도와 매칭도가 낮음 — 노출만 발생하고 클릭으로 이어지지 않는 비효율 패턴
BECAUSE 확장형 매칭은 의미적 유사어를 폭넓게 매칭하나 검색어 보고서를 보면 의도가 광고와 다른 케이스 다수(예: 시부모위자료소송, 보이스피싱반환소송 등). 정기적인 제외 키워드 등록과 일치형 비중 확대 필요
