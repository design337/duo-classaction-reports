SECTION 06 인사이트 IF · THEN · BECAUSE
메타 참여율 6일 연속 하락 = 크리에이티브 피로 IF 메타 참여율이 D-5~D 6일 연속 하락하고 신청도 5/14 정점 후 정체
THEN 기존 소재 노출 가중치를 줄이고 신규 크리에이티브 2~3종 A/B를 D+1에 투입해야 함
BECAUSE 참여율 하락은 학습 알고리즘이 단가는 유지해도 액션률 저하를 보정하지 못한다는 신호이며, 신청 정체와 동시 발생하면 CPA 상승으로 전이될 가능성이 높기 때문
네이버SA 단가 격차는 매칭/슬롯 문제 IF 네이버SA CPC가 메타 대비 약 15.5배(₩1,316 vs ₩85 추정컨대)이고 키워드별 CTR 변동이 작음
THEN 입찰가 단순 인하보다 저효율 키워드 정리 + 매칭 폭 축소(확장→문구)로 단가 구조를 재설계해야 함
BECAUSE CTR이 안정된 상황에서 CPC만 높다면 경쟁 입찰 손실이 아니라 '광고 노출이 비효율 슬롯에 분산'된 결과일 가능성이 크고, 키워드 KPI 미부여로 SA 단독 ROAS 검증이 불가능하므로 구조 정리가 선결조건
5/17 신규 머신러닝 25- 캠페인 = D+2~3 학습 변동성 IF 5/15~16 캠페인 3종 종료 → 5/17 신규 머신러닝 25- 투입
THEN 초기 2~3일은 CPC/CPA 모두 평소 대비 +20~40% 변동 추정컨대 정상 범위로 간주하고 학습 종료 후 평가
BECAUSE 머신러닝 캠페인 학습 단계 동안 단가 변동성은 알고리즘의 정상 동작이며, 이 기간에 입찰가/예산을 자주 조정하면 학습 리셋이 일어나 효율이 더 악화될 수 있기 때문
